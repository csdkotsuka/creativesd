No. 1 クリニック・店舗DX サービス提供中

CONNECT（コネクト）

24時間AI即レス予約 ＆ 顧客・スタッフ管理システム

歯科医院をはじめ、接骨院・サロン・パーソナルジムなど幅広い業種に対応する次世代予約・顧客管理システム。 LINE・WebからAIが24時間365日即時レスポンスで患者・顧客の予約受付や日時変更を自動化し、スタッフ別のタイムラインカレンダーに即時反映。 QR受付や電子カルテ・問診連携により、電話対応の手間と二重予約リスクを大幅に削減します。

主な特長・機能

  • LINE / Web両対応の24時間AI自動予約
  • スタッフ別タイムラインカレンダー＆シフト連動
  • スマホQR来院受付 ＆ 顧客カルテ連携
  • 即時SMS/メール通知・リマインド配信
Tech: React / Vite / Tailwind CSS / Supabase / LINE LIFF

No. 2 / マッチング・代行
No. 2 マッチングプラットフォーム サービス提供中

ココロモウ（Kokoromou）

お墓参り・お掃除代行プラットフォーム ＆ Stripe自動分配決済

遠方に住み訪問が難しい施主様と、地元の信頼できる石材店・霊園管理会社・清掃代行者を繋ぐマッチングプラットフォーム。 依頼から作業完了後の写真付きWeb報告書の受取・ご親族への共有までワンストップで完結。 Stripe Connect（Destination Charges）によるエスクロー決済・手数料自動分配を実装し、霊園・寺院管理会社向けの区画管理ダッシュボードも備えています。

主な特長・機能

  • オンライン申込＆高画質写真付きWeb報告書
  • Stripe Connectによる安心の自動分配・即時決済
  • 霊園・提携業者向け専用管理ダッシュボード
  • チラシ・案内DM・QRコード自動発行機能
Tech: Next.js 16 / React 19 / TypeScript / Firebase / Stripe Connect

No. 3 / セルフケア
No. 3 ヘルスケア・習慣化 サービス提供中

Cheer（チアー）

毎日に寄り添うパートナー ＆ セルフケアダイアリー

「推し活」や日々のモチベーションをエネルギーに変え、心と身体の健康（セルフケア）を両立するためのWebアプリケーション。 インタラクティブなパートナーアバターが日々の気分・睡眠・体調記録に寄り添い、温かい応援メッセージを返答。 大切なイベントや目標に向けたカウントダウン、目標達成時のリワード演出、Firebaseによるリアルタイム同期を搭載し、事業者・専門職向けPRテンプレート機能も備えています。

主な特長・機能

  • 寄り添いパートナーによる応援・対話UI
  • 気分・体調・習慣のグラフィカル記録＆推移分析
  • 目標イベントカウントダウン ＆ 達成リワード
  • 事業者・専門職向けPR＆テンプレート配信
Tech: React 19 / TypeScript / Vite / Tailwind CSS / Firebase / Chart.js
事業者向け解説を見る 使い方ガイドを見る
No. 4 / 現場・位置管理
No. 4 建設・フィールドサービスDX 社内・PoC実証運用

現場NOW（CraftSync / スタッフ管理システム）

リアルタイム現場・位置・ステータス共有 ＆ 急募レスキューアプリ (PWA)

建設会社・工務店・設備メンテナンスなど、直行直帰や急な現場呼び出しが多い少人数チーム向けに設計されたモバイルファーストWebアプリケーション（PWA対応）。 インタラクティブ地図上に現場位置と各社員の現在地・ステータス（移動中／作業中／完了／空き）をリアルタイム表示。 トラブル現場発生時は、空き状況と現在地から「最も近い社員」をAIが自動計算し、ワンタップで出動要請（レスキュー）を発行できます。

主な特長・機能

  • 現場マップ（Leaflet）× 全員ステータス一括表示
  • 🚨トラブル現場への最短スタッフ自動選定＆急募要請
  • 屋外現場・手袋でも操作しやすい高コントラストPWA
  • 「今空いてる人は？」に応えるAI自然言語アシスタント
Tech: Next.js 16 / React 19 / TypeScript / Leaflet / Firebase / PWA
実証実験・限定利用中（個別デモ・カスタマイズ相談可）
No. 5 / スケジュール管理
No. 5 ヘルスケア流通・サロンチームDX チーム内限定運用

チーム活動・スケジュール同期システム

Googleカレンダー双方向同期 ＆ スマホ最適化 チーム運営支援

某大手ヘルスケア流通企業およびサロン運営チームのセミナー・勉強会・イベント日程管理のために開発された専用Webアプリケーション。 Googleカレンダー（iCal）とサーバーサイドで定期自動同期し、常に最新の公式スケジュールを全メンバーが迷わず確認可能。 スマホに最適化された月間グリッド・リストビュー、iPhoneやAndroidの標準カレンダーへのワンタップ登録（.ics生成）、Googleマップ会場連携など、日程連絡のミスをゼロにする仕組みを構築しました。

主な特長・機能

  • Googleカレンダー（iCal）自動同期による最新性維持
  • スマホ標準カレンダー（iOS/Android）ワンタップ登録
  • 月間カレンダー ＆ 条件検索・キーワード絞り込み
  • 開催場所のGoogleマップ即時ナビゲーション連携
Tech: Next.js 15 / React 19 / TypeScript / node-ical / Tailwind CSS
